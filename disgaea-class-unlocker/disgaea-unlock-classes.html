How it works

  1. Backup your save files. Save location is (usually) C:\Program Files (x86)\Steam\userdata\102506261\405900\remote
  2. Choose the savefile you want all human classes unlocked.
  3. Make sure there are no more than 6 characters in that savefiles. A new game will contain exactly 6 and that works just fine.
  4. Upload your savefiles using the tools. The tool will add some generated characters that will unlock all classes in the assembly. It will also set the mana of the first character in your party with the valuie you input in the form. Their mana will stay the same if you leave the form empty.
  5. Optional but STRONGLY recommended: Use the assembly to delete the characters generated by the tool.
  6. Save your game and enjoy.
